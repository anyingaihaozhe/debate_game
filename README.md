# 辩士山大

**凡我在处，辩士山大**

辩士山大是一款校园辩论主题的网页卡牌游戏，目前开放内测。

[开始试玩](https://bianyu-card-game-20261124.liuxiaoennick.chatgpt.site)

## 怎么玩

1. 点「开始一局对战」，用初始四人阵容挑战电脑。
2. 在六轮中争夺印象、环节和决胜三张票。第 4、5 轮各选两名人物。
3. 结算后去「卡牌工坊」换阵容、培养人物，或回首页编辑档案和纪念品展示墙。
4. 在「开发者入口」制作人物、事件、天赋和羁绊，或导入队友分享的 JSON。

欢迎在 [GitHub Issues](https://github.com/anyingaihaozhe/debate_game/issues) 提交建议或问题。请附上所在轮次、操作步骤、预期和实际结果。试玩体验也可以只写最有趣的环节和最卡的一步。

## 当前内测范围

网页可直接打开。卡牌对战是人机模式。账号进度、原创卡牌和赛训记录保存在当前浏览器，原创内容可通过 JSON 分享。真人联机、跨设备存档和正式赛音视频尚未接入。录入赛训记录或上传卡图时，请使用获准分享的素材。

## 本地运行

网页源码位于 `dist/`，无需构建。从仓库根目录运行 `python -m http.server 8000 --directory dist`，再访问 `http://localhost:8000`。可用其他静态文件服务替代 Python。
